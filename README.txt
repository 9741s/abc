NLP Practical Programs - 11 separate .py files

Run with Python 3.9+: python Practical_01_Text_to_Speech_and_Speech_to_Text.py
Each practical is a separate executable script. Core demonstrations use Python standard-library modules and run offline. Optional integrations are skipped safely when unavailable.

Optional packages: pip install nltk spacy tensorflow gensim pyttsx3 SpeechRecognition pyaudio
Some NLTK features also need corpora/tagger data downloaded. Microphone speech recognition depends on audio drivers, permissions and internet access.

Note: These are educational demonstrations. Practical 11 calculates NWD over a small local sample collection (not a live web search); Practical 10 uses a small illustrative corpus and transparent dependency rules.
